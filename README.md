# Todo

シンプルな Todo アプリ。ビルド不要の素の HTML / CSS / JavaScript です。

## 使い方

`index.html` をブラウザで開くだけです。

```sh
xdg-open index.html   # Linux
# または任意の静的サーバー
python3 -m http.server
```

## 機能

- タスクの追加（入力して Enter または「追加」）
- 完了 / 未完了の切り替え（チェックボックス）
- タスク内容の編集（テキストをクリックして編集、Enter で確定、Esc で取り消し）
- 空にして確定するとそのタスクは削除
- タスクの削除（×）
- フィルター（すべて / 未完了 / 完了）
- 完了済みタスクの一括削除
- `localStorage` による保存（同一ブラウザで永続化、複数タブ間で同期）

## ファイル

| ファイル      | 役割                     |
| ------------- | ------------------------ |
| `index.html`  | マークアップ             |
| `styles.css`  | スタイル（ライト/ダーク対応） |
| `app.js`      | ロジック（状態・描画・保存） |
